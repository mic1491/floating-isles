# 浮光群島

免安裝的瀏覽器 3D 開放探索動作 RPG,同時支援桌面與手機。目前在 M0 原型階段,驗證手感、畫面與手機可行性。

線上試玩:https://mic1491.github.io/floating-isles/

## 操作

| 動作 | 桌面 | 手機(橫向) |
| --- | --- | --- |
| 移動 | WASD | 左側拖曳虛擬搖桿 |
| 轉鏡頭 | 滑鼠移動 | 右側單指拖曳 |
| 縮放 | 滾輪 | 右側雙指縮放 |
| 衝刺與閃避 | Shift,按住持續奔跑 | 衝刺鍵 |
| 跳躍與滑翔 | 空白鍵,空中再按滑翔 | 跳躍鍵 |
| 攻擊、技能、大招 | 左鍵、E、Q | 對應按鈕 |
| 切換角色 | 1、2、3 | 點隊伍欄 |

元素反應:火 + 水為蒸發,火 + 雷為超載,水 + 雷為感電。

## 開發

```bash
npm install
npm run dev
npm test
npm run build
```

數值集中在 `data/balance.json`。推送到 `main` 會自動部署到 GitHub Pages。
